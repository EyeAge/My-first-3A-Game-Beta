# My-first-3A-Game-Beta

《激战》（激战3A大作）：一个运行在浏览器里的第一人称射击游戏，复刻练手项目。

对照 `reference/几猫国产3A大作_V1.html`（原版 demo，只有打包后的产物，没有源码）的效果，用 Vite + TypeScript + three.js 从零重写。和原版一样，**没有任何图片、模型或音频文件**：贴图用 canvas 现画，敌人是用代码搭出来的骨骼蒙皮模型，音效用 Web Audio 现场合成。

## 运行

```bash
pnpm install
pnpm dev        # 开发：改代码后浏览器自动刷新
pnpm build      # 打包：生成 dist/index.html，单文件，双击即可打开
```

## 玩法

港区防御系统失控。切断堆场、仓库、码头三处中继，然后到码头南端登上撤离艇。

| 按键 | 作用 |
| --- | --- |
| WASD / 鼠标 | 移动 / 视角 |
| 左键 / 右键 | 开火 / 瞄准 |
| R / V | 换弹 / 近战 |
| F | 战术手电 |
| E（按住） | 切断中继 |
| 空格 / Shift / C | 跳跃 / 冲刺 / 蹲伏 |
| Esc | 暂停 |

手柄（标准布局）：左摇杆移动，右摇杆视角，RT 开火，LT 瞄准，X 换弹，Y 按住切断中继，A 跳跃，B 蹲伏，L3 冲刺，RB 近战，十字键上开关手电，Start 暂停；菜单里按 A 开始。

浏览器捕获不了鼠标时，按住鼠标拖动转视角，方向键也可以转向。手机上有触屏摇杆和按钮。

## 代码地图

按"想改什么就去哪"来读：

| 目录 | 内容 |
| --- | --- |
| `src/main.ts` | 入口：启动流程、状态切换（菜单/游戏/暂停/结算）、主循环 |
| `src/core/` | 输入、设置、数学工具（噪声、随机数） |
| `src/world/port.ts` | 港区布局：集装箱、起重机、货轮、仓库、中继、路灯 |
| `src/world/details.ts` | 场景贴花：铭牌、箱号、警示贴、锈迹、油渍、裂缝、井盖 |
| `src/world/textures.ts` | 所有贴图的生成（涂装、锈迹、标牌） |
| `src/world/atmosphere.ts` | 天空、雨、海面 |
| `src/world/colliders.ts` `nav.ts` | 碰撞盒与射线检测；A* 寻路网格 |
| `src/game/player.ts` | 第一人称移动与碰撞 |
| `src/game/gunmodel.ts` | 第一人称 M4A1 枪模和双手：用侧面轮廓挤出、横截面挤出、车削三种方式造型 |
| `src/game/clay.ts` | “捏泥巴”式建模：把一堆圆头锥融合成一整块连续表面（距离场 + 表面网），手用它 |
| `src/game/hands.ts` | 握枪的双手：分指节的黑色皮手套、腕带、手表、迷彩袖子 |
| `src/game/weapon.ts` | 步枪：开火、后坐力、换弹，以及枪模的动作 |
| `src/game/rig.ts` | 骨骼蒙皮模型：搭建工具，以及飞鸥、猎犬、守卫三副骨架和外形 |
| `src/game/enemies.ts` | 敌人的 AI，以及每帧驱动骨骼的姿势函数（步态、瞄准、扑咬、中弹） |
| `src/game/mission.ts` | 任务流程、无线电、刷怪节奏 |
| `src/render/` | 后处理（泛光、调色）、地面平面反射、粒子（火星、烟尘、水花）、弹壳与碎片、弹孔贴花 |
| `src/audio/audio.ts` | 程序化音效 |
| `src/ui/` | HUD 与菜单（DOM + CSS） |

调试：浏览器控制台里有 `__game`，例如 `__game.sim(10)` 不渲染快进 10 秒，`__game.player.pos.set(8, 0, 2)` 传送到甲号中继。

## 和原版的差距

这是第一版，先把完整的一局跑通。已经补上的：敌人的骨骼动画、弹孔和焦痕贴花、手柄支持、地面反射（中画质及以上，低画质关闭）、场景贴花与集装箱的立体框架、抛壳、碎片、烟尘和水花、带双手的 M4A1 枪模（导轨、红点瞄具、棱边磨损、雨水打湿的反光、垂直握把和可开关的战术手电）、分指节的黑色皮手套和迷彩袖子。还没做的：鼠标停在屏幕边缘持续转向、背景音乐，起重机和货轮的模型也还比较粗。
